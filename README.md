# Домашнее задание 10.1

## Описание:

Реализация функций:
- Функция принимает список словарей и значение ключа. Функция возвращает новый список словарей, содержащий только те словари, у которых ключ 
 соответствует указанному значению. 
- функция, которая принимает список словарей и необязательный параметр, задающий порядок сортировки (по умолчанию — убывание). Функция должна возвращать новый список, отсортированный по дате.
